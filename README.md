# MultiFingers

MultiFingers is a multi-profile browser.

This repository hosts the MultiFingers releases. Source code will be published here later.

## Browser kernel

The MultiFingers browser kernel is a build of [CEF](https://bitbucket.org/chromiumembedded/cef) (Chromium Embedded Framework) with MultiFingers patches. The program downloads it from this repository's Releases on first run.

| Release tag | Kernel |
|---|---|
| `cef-156.0.15-mf1` | CEF 156.0.15 (Chromium 156.0.8078.80), MultiFingers patch set 1 |

Each kernel package contains `LICENSE.txt` (CEF) and `CREDITS.html` (licenses of Chromium and its third-party components).
